# 天河体育中心周边地图可视化导航系统

基于浏览器运行的地图可视化导航系统。当前为**阶段 1：地图显示与节点管理**。

> 地图底图**必须由用户自行上传**。系统不联网获取地图，不内置任何示例地图，也不会自动替换底图。

## 技术栈

- React 19 + TypeScript 5.9
- Vite 8（开发与构建）
- Zustand 5（状态管理）
- Vitest（单元测试）+ Playwright（真实浏览器 E2E 验收）
- 地图渲染：原生 `<img>` + SVG 覆盖层，坐标与原始图片像素一一对应

## 安装与启动

需要 Node.js ≥ 20（当前环境实测 v24.16.0）与 pnpm。

```bash
pnpm install
pnpm dev
```

启动后浏览器打开终端输出的地址，默认 <http://127.0.0.1:5173/>。

生产构建与本地预览：

```bash
pnpm build
pnpm preview
```

## 使用方法

1. 在左侧“地图底图”区域点击 **选择本地地图图片**，选择你自己的天河体育中心周边地图（支持 PNG / JPG / WEBP / GIF / BMP / AVIF，≤ 60MB）。
2. 上传后可在地图区域拖动平移、滚轮缩放，或使用工具栏的“适配窗口 / 原始像素 1:1”。
3. 添加节点有两种方式：
   - 顶部切换到 **添加节点** 模式，在地图上单击；
   - 左侧“手动添加节点”中输入原始像素坐标 X、Y（可选填名称）。
4. 在“节点列表”中可以选中、改名、修改坐标、修改类型和删除节点。

## 坐标约定（重要）

所有节点坐标保存的都是**原始图片像素坐标**：

- 原点为图片左上角 `(0, 0)`；
- X 向右为正，Y 向下为正；
- 有效范围为 `X ∈ [0, 图片宽度]`、`Y ∈ [0, 图片高度]`，超出会被拒绝并提示。

缩放与平移只作用于视图（相机）层，**不会修改**已保存的节点坐标，因此任意缩放/拖动/调整窗口大小后，节点始终贴合原图位置。

## 质量检查

```bash
pnpm typecheck   # TypeScript 类型检查
pnpm lint        # ESLint
pnpm test        # Vitest 单元测试
pnpm build       # 生产构建
```

E2E 验收（真实 Chromium）需先启动开发服务器，再另开终端执行：

```bash
pnpm test:e2e
```

首次运行前需下载浏览器内核：`npx playwright install chromium`。
E2E 使用的底图是仓库根目录的 `test-map.png`（1600×1200，带像素刻度），可通过环境变量 `E2E_BASE_URL` 指定其他地址。

## 目录结构

```
src/
├─ main.tsx                  入口
├─ App.tsx                   页面布局与交互模式切换
├─ types/index.ts            数据模型（含为后续道路功能预留的 Road）
├─ lib/
│  ├─ viewport.ts            坐标变换核心（像素<->屏幕、缩放锚点、平移夹取）
│  ├─ nodes.ts               节点纯函数（ID、校验、命名）
│  ├─ imageLoader.ts         本地图片解码与校验
│  └─ constants.ts           类型标签、颜色、可接受格式
├─ store/useAppStore.ts      应用状态（底图、节点、相机、提示）
├─ components/
│  ├─ MapUploader.tsx        地图上传
│  ├─ MapViewport.tsx        地图渲染、缩放、拖动、点击取坐标
│  ├─ NodeAddPanel.tsx       手动输入坐标添加节点
│  ├─ NodeList.tsx           节点列表与编辑/删除
│  └─ NoticeBar.tsx          操作提示
└─ tests/                    单元测试
e2e/verify.mjs               Playwright E2E 验收脚本
```
